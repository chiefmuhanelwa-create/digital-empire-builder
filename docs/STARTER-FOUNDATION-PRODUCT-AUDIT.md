## What this is

An audit of Ndivhuwo's Google Drive (6 folders, links below) for existing,
already-written product content that could be revamped and shipped, filtered
specifically for the **Knowledge Entrepreneur** audience (per the locked
`contentpreneur-os/01-CUSTOMER.md` definition) — not the Struggling
Creator/Content Creator audience the Shopify store already serves.

**Important limitation:** this audit is based on file *listings* only (names, sizes,
folder structure), pulled via WebFetch on the shared Drive links — the Google Drive
MCP connector was disconnected this session, so **no file content was actually read**.
Before shipping anything below, someone needs to open each PDF and confirm it's
actually finished, on-brand, and matches its filename's promise.

## The structural idea this points toward

A **low-ticket tier sitting between the free Starter Kit/Creator Bundle and the $97
Foundation Kit** — 6-ish small, cheap, one-stage-at-a-time guides (the ones marked
"low-ticket" above), each mapped to one of the 7 stages. Two things this would fix at
once:
1. Gives the 7-email Creator Bundle sequence (`CREATOR-BUNDLE-SEQUENCE.md`) real,
   distinct products to point to per stage, instead of circling back to the same 2
   original workbooks every time.
2. Fills the gap between "free" and "$97" that doesn't currently exist on
   `contentpreneur.africa` — right now the jump from Starter Kit to Foundation Kit is
   Free → $97 with nothing in between.

## Before building any of this

1. **Actually open and QC every file** — this audit never read file content, only
   names/sizes. Some may be unfinished, off-brand, or not what the filename implies.
2. **Check for duplicate/competing versions** — several titles exist in 3+ folders at
   different completion stages (half-finished P-numbered draft → "ready" master →
   "published" final). Confirm which is genuinely the latest/best version before using
   any of them; don't assume "published" always wins without checking dates.
3. **Confirm pricing against the real product ladder** — cross-check against
   `Contentpreneur Africa/knowledge-base/Canonical Registry/CANONICAL_PRICING.md`
   before setting any price, don't invent new numbers.
4. **Community-stage gap** — this is real net-new work, not a revamp. Flag separately
   if it becomes a priority; it wasn't solved here.
